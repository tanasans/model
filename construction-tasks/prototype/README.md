# 試作画面（建設案件タスク管理）

ブラウザだけで動く、クリックして操作できる試作です。サーバーは不要です。
入力した内容はそのブラウザにだけ保存されます（サンプルの日付を今日に合わせるため、日付が変わると初期状態に戻ります）。

## 開き方
- `index.html` をブラウザで開く（PC・スマホどちらでも可）
- GitHub Pages を有効にすると `https://<ユーザー名>.github.io/model/construction-tasks/prototype/` で社内に回覧できます

## 試してほしい流れ
| 立場（ログイン画面で選択） | 試すこと |
|---|---|
| 佐藤（営業・一般） | 案件一覧 →「案件を登録」→ 条件を選ぶ → 生成タスクを確認・除外 → 登録 |
| 田中（設計・一般） | 他部署のタスクは閲覧のみ／自分のタスクで「打ち合わせ完了」「期限変更を申請」 |
| 伊藤（設計・所属長） | 承認待ち → 期限変更申請を承認／届いた依頼を「期限を変更して承認」 |
| 加藤（工務・一般） | 届いた依頼に対応／「工程がずれました」→ 後続タスクへの影響を確認 → 申請 |
| 山本（工務・所属長） | 保育園の工程変更申請を、一部タスクを除外して承認 → 一括反映 |
| 中村（役員） | 部署別の負荷、機密情報（原価・粗利）の閲覧 |
| 小林（システム管理者） | 案件条件・タスクテンプレート（生成条件・締切計算）・権限表の編集 |
| 森（閲覧者） | 閲覧のみになることの確認 |

## ファイル
- `engine.js` … マスタ（案件条件・テンプレート・権限）、自動生成、締切計算、工程変更の影響計算、サンプルデータ
- `app.js` … 画面と操作
- `style.css` … スマホ／PC 両対応のレイアウト（ダークモード対応）
