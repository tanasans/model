# 自分専用AI秘書（日本語音声・ローカルMVP）

Windows PC の Chrome で「会話開始」を押して日本語で話すと、AI が日本語の音声で答える最小構成です。
OpenAI の GA 版 Realtime API（WebRTC）と公式 SDK `@openai/agents/realtime` を使います。

> このフォルダは独立しています。リポジトリ内の他のファイル（モデルルーム予約システム等）には依存も変更もしていません。

## 構成

```
personal-voice-assistant/
├─ server/index.ts        … ローカルAPIサーバー（Express、127.0.0.1:8787 のみで待ち受け）
├─ src/                   … 画面（React + TypeScript + Vite、127.0.0.1:5173）
│   ├─ App.tsx            … 画面（ボタン・状態・エラー・会話表示）
│   └─ useVoiceSession.ts … マイク取得 → 一時トークン取得 → WebRTC 接続 → 確実な切断
├─ shared/assistant.ts    … 秘書への指示文・共通の型（秘密情報なし）
├─ .env.example           … 環境変数のサンプル（.env は Git に含めない）
└─ README.md
```

### 通信の流れとセキュリティ

1. 「会話開始」→ Chrome がマイク使用の許可を求める。**許可された場合だけ**次へ進む。
2. ブラウザ → ローカルサーバー `POST /api/session`。サーバーは `.env` の APIキーで
   OpenAI の **`POST /v1/realtime/client_secrets`（GA）** を呼び、**有効期限60秒の短命 client secret** を発行してブラウザへ返す。
   通常の APIキーはブラウザに一切渡りません（旧ベータの `/realtime/sessions` は使いません）。
3. ブラウザは短命 client secret で OpenAI と **WebRTC** 接続（`/v1/realtime/calls`）し、音声で会話。
4. 「会話終了」/ 最大時間到達 / エラー / 切断 / タブを閉じる → WebRTC・マイク・音声再生を閉じ、サーバーのセッション枠を解放。

課金の暴走を防ぐしくみ：

| 対策 | 内容 |
| --- | --- |
| 明示的な開始・終了 | ボタン操作でのみ接続。常時待機・自動起動なし |
| 最大継続時間 | 既定 300 秒（`MAX_SESSION_SECONDS`、上限 1800）。ブラウザ側で自動切断し、さらにサーバー側でも期限到達時に OpenAI の通話を切断（hangup API） |
| 同時セッション数 | サーバー全体で同時 1 件のみ（2件目は拒否） |
| 開始の連打防止 | 3 秒以内の再発行は拒否 |
| エラー時切断 | 通信エラー・接続断を検知したら即座に全て閉じる |
| 接続元制限 | サーバーは 127.0.0.1 のみで待ち受け。`Origin` が localhost 以外の要求を拒否（他サイトからの不正発行防止） |

ログ方針：APIキー・短命トークン・音声・会話内容は出力しません（エラーの種類と HTTP ステータスのみ）。
SDK のトレース送信（`tracingDisabled: true`）と音声の履歴保持（`historyStoreAudio: false`）も無効化しています。音声録音の保存機能はありません。

### 使用モデル（2026-11-05 時点、インストールした公式パッケージの型定義で確認）

- 会話モデル：`gpt-realtime-2.1`（`@openai/agents` 0.21.0 の既定値。`.env` の `REALTIME_MODEL` で変更可。安価な `gpt-realtime-2.1-mini` 等も指定可能）
- 入力の文字起こし：`gpt-4o-mini-transcribe`（言語 `ja`）
- 声：`marin`（`REALTIME_VOICE` で変更可）

## Windows での使い方

### 1. Node.js の確認

PowerShell を開き、次を実行します。`v20.19` 以上（推奨 v22 LTS 以上）が表示されれば OK です。

```powershell
node -v
npm -v
```

表示されない・古い場合は https://nodejs.org/ から LTS 版をインストールしてください。

### 2. 依存パッケージのインストール

```powershell
cd <このリポジトリの場所>\personal-voice-assistant
npm install
```

### 3. 環境変数の設定

```powershell
copy .env.example .env
notepad .env
```

メモ帳で `OPENAI_API_KEY=` の右側に、OpenAI の管理画面（https://platform.openai.com/api-keys ）で作成した APIキーを貼り付けて保存します。
**APIキーはチャットやメール、Git に貼らないでください。** `.env` は `.gitignore` 済みです。

### 4. 起動

```powershell
npm run dev
```

`listening on http://127.0.0.1:8787` と `Local: http://127.0.0.1:5173/` が表示されたら起動完了です。

### 5. Chrome で確認

1. Chrome で **http://localhost:5173** を開く（開けない場合は http://127.0.0.1:5173 ）。
2. 「サーバー：起動中・APIキー設定済み」と表示されることを確認。
3. 「会話開始」を押し、マイクの許可を求められたら「許可する」。
4. 状態が「接続中（話しかけてください）」になったら日本語で話しかける（例：「こんにちは、今日の予定を立てるコツを教えて」）。
5. AI が日本語の音声で答え、画面に文字起こし（取得できた分のみ）が表示されます。
6. 「会話終了」を押すと、マイク（タブのマイクアイコン）と接続が閉じます。再度「会話開始」で再開できます。

APIキー未設定でも画面は開けます。その場合「会話開始」を押すとマイク許可の後に
「サーバーに OPENAI_API_KEY が設定されていません」と表示され、接続成功のようには見えません。

### 6. 停止

`npm run dev` を実行している PowerShell で **Ctrl + C** を押します（「バッチ ジョブを終了しますか」と聞かれたら `Y`）。

### その他のコマンド

```powershell
npm run typecheck   # 型チェック（クライアント・サーバー）
npm run build       # 型チェック + 本番ビルド（dist/client）
npm start           # ビルド済み画面をサーバーから配信 → http://localhost:8787
```

## 想定料金と API 課金の注意（必ずお読みください）

- Realtime API は **音声の入力・出力トークン量に応じた従量課金** です。音声は文字より単価が高く、話す時間・AI が話す時間に比例して増えます。
  文字起こし（`gpt-4o-mini-transcribe`）も別途課金されます。
- 目安（概算・未検証）：過去の GA 版 `gpt-realtime` の公開単価から計算すると、**会話 1 分あたりおおむね数円〜数十円程度**になり得ます。
  実際の単価はモデル（`gpt-realtime-2.1` / mini 等）や会話内容・長さで変わります。**最新の正確な単価は必ず公式の料金ページ（https://openai.com/api/pricing/ ）で確認してください。**
  - 例：最大 300 秒の会話を 1 日 10 回行うと、1 日最大 50 分の通話になります。
- **このアプリ側の制限だけでは課金上限になりません。** OpenAI の管理画面（https://platform.openai.com/ の Settings → Limits / Billing）で
  **月の予算上限（Budget）・通知（Usage alerts）を必ず設定**してください。プリペイド（Credit）残高を少額にしておくのも有効です。
- 会話後は必ず「会話終了」を押してください（押し忘れても最大継続時間で自動切断されます）。

## トラブルシューティング

| 表示 | 対処 |
| --- | --- |
| マイクの使用が許可されませんでした | アドレスバー左のアイコン →「マイク」を許可 → 再読み込み。Windows の「設定 → プライバシー → マイク」で Chrome を許可 |
| ローカルサーバーに接続できません | `npm run dev` が動いているか確認 |
| OpenAI の認証に失敗しました | `.env` の APIキーを確認し、サーバーを再起動（Ctrl+C → `npm run dev`） |
| 利用上限またはレート制限 | OpenAI 管理画面の Billing / Limits を確認 |
| すでに会話中のセッションがあります | 別タブで会話中でないか確認。ブラウザ異常終了時は最大継続時間 + 15 秒で自動解放（またはサーバー再起動） |
| ポート 5173 / 8787 が使用中 | 他のアプリを終了するか、`.env` の `PORT` を変更（変更時は `vite.config.ts` のプロキシ先も同じ番号に） |
